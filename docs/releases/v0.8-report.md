# v0.8.0 命运开端验收报告

## 实际实现
职业自动绑定瓦尔铎/诺克斯/艾蕾娅；发行版采用任务书授权的原创魔法女神替代名称，不使用D&D官方神徽、立绘或设定文段。小镇(3,16)与已发现的地牢入口可祈祷，每游戏日一次。神眷0～100、神迹消耗35且每战一次；三职业的守护、紧急脱离与秘法恢复都改变真实结算。

等级1～5/XP曲线0、24、65、120、200，来源一次结算；生命/命中/技能路线自动选择。三装备槽，3初始武器与9职业候选装备；商店、实际开启成功的宝箱、成功委托提供装备，自动效用比较与真实参数重算。背景设定等级仍单独保留。

六技能均有真实成本/回合/效果；普通攻击保留d20、自然1/20，魔法明确稳定伤害且有限MP。战斗反击/保命不复活已死亡角色。绘图不推进规则、不耗随机源，动画可关闭并尊重减少动画；关键事件不会只闪过。v0.7原CC0地图/肖像/角色原样保留，新增徽记与特效为原创代码绘制。

- node tests/fate.cjs：48配置120000自然行动，六技能与三神迹均实际出现；有限奖励、等级/装备真实效应、祈祷位置/冷却、神迹成本/敌方回合、死亡停止、旧卡/存档迁移、同状态续演通过。
- node tests/world.cjs：120配置595105行动，120进入遗迹、119完成、1自然死亡，14事件/因果/数值不变量通过。

## 修复与局限
修复临近闭店合法交谈失去在场条件的边界；放弃侧室/封印宝箱/失败调查不会凭空得到护甲。旧存档保留既有时间、HP/金币/物品、历史与RNG，补齐默认初级成长，不承诺跨版本行为完全相同。没有新主线或完整结局（按顺序留待v0.9），没有复杂法术/多目标/官方D&D全规则。
