# v0.7.0 像素奇幻视觉重制报告

## 实际交付
真实官方 CC0 tileset/sprite 替换主视觉：连续土路/树林/木构小镇、原位置NPC/角色、岩洞入口、真实地砖/墙面/宝箱/骷髅；四方向两帧行走、待机、像素肖像、Kenney九宫格人物卡与真实物品图标。地图仍21×21/25×25，技能和其他玩法未在本版增加。原核心五个规则文件与 v0.6 相同（自动校验）。

地牢13×13局部视野可切25×25全图；未知格最终黑色遮罩，不被精灵边缘泄露。仅绘图层用坐标哈希，无游戏随机数消耗；动画最长180ms、暂停取消，减少动画偏好受尊重。底图按道路或已知格/走过格缓存，避免加速绘制超时。

## 素材与决定
官方 Ninja Adventure（Pixel-Boy/AAA）与 Kenney Fantasy UI Borders，22 PNG 190156字节，连许可197672字节，运行包约345222字节。原89MB包只保存在忽略目录；不引入忍者/鸟居/亚洲屋顶、音乐或 Godot。原包逐项路径与SHA见 ASSETS/CREDITS/manifest。窗框保留透明度着棕色，其余PNG未改字节。

人物卡加入38px原作者头像、六维与可读修正值、HP/AC、金币/药水、实际目标/武器；修正值仅展示，不重算旧规则。地图为主，纪事/背包/NPC按需展开；360/390px提供地图/人物/纪事触控切换与更多操作，按钮至少44px。

## 局限
森林装饰布局较规整，暗色石墙/地砖变化有限；NPC仍为原小时日程位置变化，没有新增行走机制；没有复杂战斗特效。缩小全图像素会减少细节，默认跟随改善地牢手机观察。素材失败时才使用旧程序后备，正常主视觉没有程序角色/树/宝箱占位；阴影/文字/目标轮廓/迷雾仍由Canvas画。
