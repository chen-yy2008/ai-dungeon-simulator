# v0.5.0 鲜活世界报告

## 已实现
四 NPC 日程、可互动位置、关系 -100～100、最多 24 条记忆；五个有前置条件、接受/婉拒、现场结果与跨日回访的有限委托。商队真正获得/交付货物，哨兵使用原真实战斗，草图来自实际探索，研究消耗药水，借款按金币或实际两小时劳动偿还。一次性报酬不能刷取。

## 架构与兼容
living-world.js 负责有限 NPC/链状态，World.advance 驱动日程，Simulation 记录实际后果并协调原系统。旧 v0.3/v0.4 缺 NPC 字段时添加默认状态，已有世界标记与原商人救助保持。NPC 不连续寻路移动，日程在小时边界切换位置。

## 修复与测试
发现并修复旅行商人未返镇时角色无限等候的路线循环。普通安全错误自行修复，没有关闭测试。
- `node tests/world.cjs`：600000 次行动 / 120 配置，全部进入且完成遗迹，资源/存取/终止不变量通过。
- `node tests/living-world.cjs`：四日程、五链成功/失败/拒绝、跨日存取、有限奖励、借款劳动、不可达商人等待通过；36000 固定种子复现行动。
- `node tests/browser.cjs`：控制、场景、存取、1500 行动与人物卡/窄屏检查通过。核心和 Pages 打包检查随发布门禁再次执行。
- 旧系统的确定性死亡检查仍保留；自然模拟中没有死亡不等于不会死亡。

## Pages 与发布
Pages 已采用官方 gh-pages 分支式部署：仅经测试的正式标签运行文件进入站点，main 日常提交不更新网站。v0.4.0 的 HTTP version.json 已核对标签源 SHA；在线 Chrome 全交互检查通过。自定义 Actions 模板仍保留，workflow 补充授权过期，未绕过权限写入工作流。
仓库 https://github.com/chen-yy2008/ai-dungeon-simulator；本版计划标签 v0.5.0，实际发布后的 SHA 与部署结果写入进度并由下一阶段记录补充。
