# v1.1.0 — 玩家体验增强验收报告

基于已发布并核验的v1.0.0（9df5738），独立feat/v1.1-player-experience开发，完整阅读用户395行任务书后实施。不重做世界、战斗、主线或CC0地图，不加后端/API/账号。

## 实际交付

- 九段史官教学：原创Canvas鸦羽、像素羊皮纸、话题/进度、四向遮罩与聚焦。依真实地图、居民、地牢、战斗、成长解锁；上一步、下一步、跳过、80实际动作后提醒、重播、设置重置。旧schema1完成/跳过不强制重教；提前结束不伪造未发生的遭遇。
- 史官陪伴面板与九类四变体旁白，结合职业/神明/性格，完整、简洁、关闭三模式。正文忠于实际事实；关闭仍保留事实日志与结算，不禁用教学说明。
- 最多8条反馈缓存、UI最近3张关键卡；首次实际施展技能、成长、装备、神眷、神迹、NPC关系delta、主线/结局。独立目标变更有12动作冷却；战斗卡显示实际行动、命中/落空、伤害与特殊结果。
- 六个一键预设，各有五项性格、目标、职业绑定神明与起行宣言。金甲/查访者/橙袍三组肖像与四方向动画来自既有官方Ninja Adventure CC0原包；新增6PNG，基础22图未改，累计215246字节。鸦羽是原创程序绘图，不伪造世界NPC。
- 五命运图鉴、最多30条本地英雄名册，真实完成/死亡才收录；同设定/种子/结果去重，独立版本化存储。局后关键事实时间线、重要选择、代表交锋、命运评价、鸦羽结语、再次出发/分享。
- 手机聚焦自动切地图/人物/纪事；44px教学按钮与窄屏对话框。保留暂停、倍速、离线运行、旧存档与战报/Markdown下载。

## 系统边界

chronicles.js提供只读反馈/结算与名册模型，comfort-ui.js负责独立观看设置、原创头像和UI；tutorial.js只管理教学状态。world.js仅补实际起行宣言与安全存档校验，living-world.js在既有关系真实变化后记录before/after/delta，story-rules.js保留这些重要事实。均不额外推进时间、发奖或消费规则随机数。

存档format3保持兼容，教程schema2加法迁移，观看偏好/名册schema1分开。损坏/重复ID名册不覆盖原始数据，存储拒绝在本页安全回退，仍可下载故事。无云同步，清理浏览器存储会丢失本地记录。

## 已知局限与取舍

没有加入可选新事件/装备机制/昼夜或语音，优先本轮体验。世界与剧情有限，规则型AI不是LLM；模板旁白仍可能重复。名册保留最多30局，相同条件结果合并。真实实体手机、iOS/Safari、屏幕阅读器全流程与真人长时审美尚未专项验证；移动证据为Windows浏览器设备仿真与实际触摸输入。
