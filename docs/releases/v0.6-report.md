# v0.6.0 角色系统进化报告

## 实际交付与架构
character-card.js 是纯数据校验/适配接口；card-editor.js 只填表和下载，script.js 确认后才新建 Simulation。world.js 复用原资源、探索和战斗，给角色添加 profile 并扩展 Agent 风险/事件评分；living-world.js 对接价值观与社交弱点。没有 LLM、网络人物查询、多人或法术。

卡包含姓名、身份、背景、职业、等级、六维、性格、价值观、行为、机械目标、短/长期愿望、描述能力、弱点、记忆。schema=ai-dungeon-character / version=1；最多 64 KB、已知字段/枚举、整数范围与文本/列表限额。任何导入都不接收 HP、金币、背包、NPC 关系、世界标记。未知旧角色卡版本清晰拒绝；既有冒险存档格式 3 加法迁移，没有移除保存键。

## 决策与范围选择
冒险意愿调整健康阈值、自律调整疲劳阈值、助人倾向和价值观调整事件/委托评分；亡灵恐惧等四弱点作用于相关规则。默认 50 行为和空价值观维持旧策略。等级 1～20 与六维只描述设定，不强改原战斗参数；文本目标/能力不被当成可执行规则，避免假装理解任意角色背景。

## 已执行测试
- 核心 300 张地图和 300 轮带战斗模拟持续保留。
- 世界 120 配置 / 600000 行动检查通过；默认配置全部进入并完成遗迹，死亡有确定性夹具，不把自然死亡数量等同胜率。
- NPC/五链所有分支、存取、有限奖励与 36000 行动复现通过。
- 角色校验/回导、拒绝非法和运行数据、背景隔离、旧存档、同条件行为对比与 24000 行动及存取续演通过。
- Chrome/Edge：全旧交互与 1500 行动、非法导入保持当前状态、合法导入/六维/设定等级、文字显示、实际文件下载、编辑新建、390px 无横向溢出通过。
- Windows PowerShell 发布保护测试在版本文档同步前拒绝了缺少 v0.6 CHANGELOG 的夹具；修齐实际文档后重新验证，不关闭门禁。最终 Windows PowerShell 5.1 集成检查 13 个本地用例全部通过；正式发布 DryRun 全门禁通过。
