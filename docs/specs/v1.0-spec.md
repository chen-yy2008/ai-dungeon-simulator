# v1.0 正式版规格

开场复用像素场景，提供开始/继续/观看示例/教程/玩法。简化创建，三职业三个角色预设一键启动，高级JSON可选。死亡或阶段结束展示实际称号/职业神明/选择/关系/成长/战绩/回忆；重开/返回观察/导出故事。

客户端复制战报和Markdown故事Blob下载，保留角色卡导出；分享只读真实事实，不复制密钥/个人资料，不放巨大存档进URL。手机375～430px触控、人物/日志/教程/结局/分享无溢出。自动保存、旧迁移、异常JSON处理和最差配置可前进或合理失败。

示例冒险使用真实规则稳定种子和速度，无预写虚假结算。端到端从首页到结局必须真实浏览器截图/计时证据；一分钟内可启动、等量逻辑行动观察职业/神明并合理结局，报告虚拟加速与真人时长限制。全回归、至少数万次长期逻辑、Chrome/Edge/手机、部署所有素材/版本/SHA核验。README30秒上手、素材许可、预设与限制。完成1.0停止，不开发1.1。
