# v0.9 命运编织规格

复用原五委托，三主线分阶段并有跨时间/地点的后果：《失踪商队与黑森林契约》接商队调查/哨兵，《遗迹中的星辉法阵》接测绘/研究，三碑→遗迹真实互动→封印/净化/能量分支，非巫师也有调查合作路径；《旅馆的最后一封信》接米菈与债务/探索记忆，帮助/漠视/隐瞒/牟利分支。为每阶段记录条件、地点、消耗/耗时、标记、失败/拒绝、重复防护与存取。至少四类关系后果：价格/住宿、委托门槛、情报、危机援助。

史官鸦羽原创。新手引导独立存储、首次/跳过/重看/下一步，桌面侧卡手机底卡，必要暂停保持恢复前状态。按实际创建/进入/NPC/战斗/升级/保存/结局推进，不提前伪造骰点。动态旁白只消费事实，九类事件多模板、节流、无世界写入和游戏随机源消耗。语音可选不阻断。

关键事实索引保留事件ID和时间，传记章节据此生成；五结局有条件和优先级，默认阶段有合理行动/时间收束，不能无限采集。测试三主线所有核心分支和拒绝/失败/存取、四关系后果、教程/旁白事实一致性、不同职业性格不同真实结局、全回归/实景/Pages。
