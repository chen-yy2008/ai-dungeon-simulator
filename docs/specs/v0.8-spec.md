# v0.8 命运开端规格

先决条件：v0.7正式标签、视觉与Pages核验。复用World/Agent/Combat/角色卡/CC0图集；在新分支实施，禁止并行改v0.7。

必须：职业自动绑定原创神明（战士瓦尔铎、游荡者诺克斯、发行版法师星织女神艾蕾娅，未确认许可时不复制指定D&D角色）。角色卡新schema兼容version1，patronId与职业一致。恩典0～100，实际到小镇神龛或已发现遗迹神龛祈祷、每游戏日冷却；符合信条的行动和探索/委托两类有限来源。每职业一次实际神迹，成本/条件/记录。

成长：combatLevel1～5、有限来源XP、自动选择生命/命中/技能成长，旧设定level不转战力。装备武器/护甲/饰品三槽，至少九候选、各职业三件、商店/宝箱/奖励、真实属性重算和效用换装。

技能：盾击/守护姿态、背刺/灵巧脱离、奥术飞弹/霜缚术；法力与恢复、限次/冷却、消耗行动，不跳过敌人/重复奖励。视觉只消费实际结果，命中/治疗/神迹/升级/装备反馈，近期战斗卡可浏览理由。

验收：三职业同种子等量行动，技能/神迹/升级/换装确实发生；数值与回合不变量、旧保存/角色卡迁移、存取复现；全旧门禁、Chrome/Edge/390px、神迹/升级截图；发布和Pages核验后才v0.9。
