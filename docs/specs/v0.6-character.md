# v0.6 规格

版本化角色卡包含身份、背景、职业、等级、六维、性格、价值观、行为倾向、短/长期目标、能力、弱点、记忆。创建时可编辑，JSON 导入导出只解析数据并严格验证，不执行代码。采用旧战斗原型，属性暂不重新推导伤害；行为字段必须影响决策并有固定条件对比测试。不导入角色卡里的运行时 HP/金币以防破坏资源规则。

实现边界：schema ai-dungeon-character/version 1，编辑必须新建冒险。六维3～20/等级1～20是设定，不改变职业战斗数值；背景记忆不创造世界标记。行为 riskTolerance/altruism/discipline 各0～100，六价值观与四规则弱点产生评分修正，默认50保持旧策略。短/长期文本与能力描述不执行。测试覆盖非法输入、实际导出下载、旧存档、同资源行为对比和24000模拟行动。
